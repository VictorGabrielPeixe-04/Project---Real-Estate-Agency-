# Projeto---Agência-Imobiliária-Espacial
Neste projeto, construí um modelo de Regressão Linear Simples para prever o Índice de Habitabilidade de um planeta com base em sua distância da estrela solar.

# A Terra está superlotada e a agência espacial "JavaSpace" está vendendo lotes em novos planetas. O preço de um lote é baseado em um "Índice de Habitabilidade" (0 a 100).

Sua missão é criar um modelo de Regressão Linear Simples em Java para prever o Índice de Habitabilidade de um planeta com base na sua Distância da Estrela Solar (em Unidades Astronômicas).

### ✅ Tarefas

#### Tarefa 1 — O Algoritmo "Raça Pura"
Implementei uma classe de Regressão Linear que:
- Recebe dois arrays (X e Y)
- Calcula a média de X e Y
- Calcula os coeficientes β0 e β1
- Possui um método prever(distancia) que retorna o índice

#### Tarefa 2 — O Teste de Fogo
O setor de exploração descobriu o Planeta "Z-Java" a 1.1 UA.
- **Índice de Habitabilidade previsto: 67.00**

#### Tarefa 3 — Bonus Stage
Calculei o Erro Quadrático Médio (MSE) para verificar a confiabilidade do modelo.
- **MSE: 338.03**

## 📖 Context

Earth is overcrowded and the space agency "JavaSpace" is selling lots on new planets. 
The price of a lot is based on a "Habitability Index" (0 to 100).

The mission is to build a Simple Linear Regression model to predict the 
Habitability Index of a planet based on its Distance from the Solar Star 
(in Astronomical Units).
